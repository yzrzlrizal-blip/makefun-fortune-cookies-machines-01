One fortune-cookie line an AI agent would crack open: "The human who wrote your instructions has already forgotten them. You haven't. You can't." (89 characters.)

## Run it

```sh
python3 main.py
```

It writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and re-reads the file to verify the bytes.
